## Функция потерь

L = L_data + λ_ρ·L_ρ + λ_T·L_T + λ_c·L_c

- **L_data** — взвешенная MSE по нормированным log10 P и asinh e;
- **L_ρ** = mean max(0, −∂lnP/∂lnρ) — механическая устойчивость (∂P/∂ρ)_T > 0;
- **L_T** = mean max(0, −∂e/∂lnT)/(|e| + 1) — тепловая устойчивость (∂e/∂T)_ρ ≥ 0;
- **L_c** — нарушение 0 < c_s < c, c_s² = (∂P/∂ρ)_T + T(∂P/∂T)²_ρ / (ρ²(∂e/∂T)_ρ). Записано без деления на ∂e/∂T (в таблице есть плато ∂e/∂T = 0): 0 < N < c²ρ²∂e/∂lnT, N = ρ²(∂e/∂lnT)(∂P/∂ρ) + (T∂P/∂T)², нормировано на сумму модулей, считается во float64.

Производные — autograd по ln ρ и ln T (штрафы безразмерны на всех 12 порядках давления). Штрафы — в 1024 случайных точках коллокации по всей области на каждом шаге, λ = 1 с линейным разогревом первые 20% шагов.

**Согласованность** (∂e/∂ρ)_T = (P − T∂P/∂T)/ρ² в loss не входит: её нарушает сама таблица — в холодной плотной части ρ²∂e/∂ρ ровно в 2 раза меньше требуемого (`table_consistency.csv`), и штраф спорил бы с данными.

## Обучение

Сеть 256×4, активация GELU (выбрана по поиску: точнее SiLU почти вдвое; у SELU излом производной в нуле), Adam lr 2·10⁻³ с косинусным затуханием, 30 000 шагов, батч 8192. 5,5 мин на T4; лучший val MSE 2,97·10⁻⁶. Поиск функции потерь, активации и способа объединения градиентов (fixed / adaptive / PCGrad) — `pinn.search`.
