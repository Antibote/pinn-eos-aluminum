# Модуль 2. Vanilla MLP

**Ответственный:** Елагин Матвей · **Ноутбук:** `notebooks/pinn_eos_colab.ipynb`, раздел 2

## Что сделано

- Сеть 2 → 256×4 → 2 (SiLU), 198 658 параметров; вход — нормированные (log ρ, log T), выход — нормированные (log10 P, asinh e).
- Обучение: взвешенная MSE (веса из модуля 1), AdamW (lr 10⁻³, weight decay 10⁻⁵), ReduceLROnPlateau, батч 8192, до 300 эпох с early stopping; лучший val MSE 5·10⁻⁵.
- Производные ∂P/∂ρ, ∂P/∂T, ∂e/∂T через autograd; карты ошибок и нарушений.
