## Идея

На CPU время PINN 256×4 определяется умножением матриц 256×256 (395 тыс. операций на запрос). Оптимизации:

1. **Дистилляция**: сети 128×4 и 64×4 учатся у PINN 256×4 (учителя) — на данных таблицы, на ответах учителя в случайных точках всей области и с теми же физическими штрафами.
2. **float16-веса** — вдвое меньше файл.
3. **ONNX Runtime** на CPU.
4. **Смешанная точность** на GPU (`torch.autocast`, матрицы во float16, log/pow/sinh во float32).
5. **SVD-сжатие внутренних слоёв** (5.4): каждая матрица 256×256 заменяется лучшим приближением ранга r — W ≈ (U_r S_r) V_rᵀ, два слоя 256→r→256; первый (2→256) и последний (256→2) слои не трогаются — они маленькие и критичны для физики. Затем «безопасный путь»: дообучение 1000 шагов с теми же физическими штрафами и исходной PINN в роли учителя.

## Результаты (пробное обучение учеников — 3000 шагов)

| | PINN 256×4 | 128×4 | 64×4 |
|---|---|---|---|
| файл float16 | 0,38 МБ | 0,10 МБ | **0,028 МБ** |
| ошибка P / e (медиана) | 0,23% / 0,25% | 3,6% / 4,2% | 5,7% / 3,8% |
| CPU, ONNX Runtime | 0,54 с | 0,18 с | **0,083 с** |
| GPU, float16 | 0,006 с | 0,004 с | 0,002 с |

Эффект относительно PINN 256×4 (float32, PyTorch, CPU): 128×4 — в 7,6 раза меньше и в 4,5 раза быстрее; 64×4 — в 27 раз меньше и в 9,9 раза быстрее (быстрее билинейной интерполяции). Смешанная точность на GPU ускоряет PINN 256×4 в 3,8 раза (ошибка P 0,23% → 0,39%). Учитель важен: на CPU 64×4 за 15 000 шагов с учителем — 2,5% по P, без учителя — 6,5%.

## SVD + дообучение (5.4)

Веса внутренних слоёв не низкоранговые: при r = 64 первые сингулярные числа несут 85–90% Σσ², и обрезка без дообучения разрушает модель. Дообучение 1000 шагов возвращает точность (замер на CPU, test):

| | параметров | файл float16 | ошибка P / e (медиана) | нарушения ∂P/∂ρ, ∂e/∂T, c_s |
|---|---|---|---|---|
| PINN 256×4 | 198 658 | 0,38 МБ | 0,23% / 0,25% | 0% |
| SVD r = 64, без дообучения | 100 354 | 0,20 МБ | 17,7% / 12,7% | 11,6% / 6,1% / 0,1% |
| **SVD r = 64 + 1000 шагов** | **100 354** | **0,20 МБ** | **0,34% / 0,39%** | **0%** |
| SVD r = 32 + 1000 шагов | 51 202 | 0,10 МБ | 0,44% / 0,52% | 0% |

SVD + дообучение в 10 раз точнее дистилляции при сопоставимом размере (128×4: 0,10 МБ и 3,6%), потому что стартует с весов обученной сети. Результаты в ноутбуке: `metrics_svd.csv`, `figures/svd_compression.png`, модели `optimized/pinn_svd64_fp16.pt`, `pinn_svd32_fp16.pt` и их ONNX-версии.
