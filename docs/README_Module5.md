# Модуль 5. Сжатие и скорость работы (дополнительный этап)

**Ответственный:** Селивохин Ярослав · **Ноутбук:** раздел 5 (или `notebooks/section5_optimization.ipynb`) · **Код:** `src/eos/pinn.py` (`Trainer.fit(teacher=...)`), `src/eos/inference.py`

## Идея

На CPU время PINN 256×4 определяется умножением матриц 256×256 (395 тыс. операций на запрос). Оптимизации:

1. **Дистилляция**: сети 128×4 и 64×4 учатся у PINN 256×4 (учителя) — на данных таблицы, на ответах учителя в случайных точках всей области и с теми же физическими штрафами.
2. **float16-веса** — вдвое меньше файл.
3. **ONNX Runtime** на CPU.
4. **Смешанная точность** на GPU (`torch.autocast`, матрицы во float16, log/pow/sinh во float32).

## Результаты (пробное обучение учеников — 3000 шагов)

| | PINN 256×4 | 128×4 | 64×4 |
|---|---|---|---|
| файл float16 | 0,38 МБ | 0,10 МБ | **0,028 МБ** |
| ошибка P / e (медиана) | 0,23% / 0,25% | 3,6% / 4,2% | 5,7% / 3,8% |
| CPU, ONNX Runtime | 0,54 с | 0,18 с | **0,083 с** |
| GPU, float16 | 0,006 с | 0,004 с | 0,002 с |

Эффект относительно PINN 256×4 (float32, PyTorch, CPU): 128×4 — в 7,6 раза меньше и в 4,5 раза быстрее; 64×4 — в 27 раз меньше и в 9,9 раза быстрее (быстрее билинейной интерполяции). Смешанная точность на GPU ускоряет PINN 256×4 в 3,8 раза (ошибка P 0,23% → 0,39%). Учитель важен: на CPU 64×4 за 15 000 шагов с учителем — 2,5% по P, без учителя — 6,5%.
