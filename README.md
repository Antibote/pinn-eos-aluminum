# PINN для уравнения состояния алюминия

Кейс 02 (Machine Learning) хакатона «ИТ КоР 5.0» (Росатом): **нейросетевая аппроксимация широкодиапазонного уравнения состояния вещества с учётом термодинамических ограничений**.

Задача — обучить физически-информированную нейросеть (PINN), которая по плотности ρ и температуре T выдаёт давление P(ρ,T) и удельную внутреннюю энергию E(ρ,T), считает производные ∂P/∂ρ, ∂P/∂T, ∂E/∂ρ, ∂E/∂T и скорость звука c_s, а также соблюдает термодинамические ограничения.

## Данные

Датасет: https://disk.yandex.ru/d/iUSbYrJcsbXSbw. Скачать и положить файлы `Obl01.txt … Obl20.txt` в `data/` (в git не попадают, ~75 МБ).

- 20 областей (4 диапазона ρ × 5 диапазонов T), ~1,13 млн точек
- колонки: `rho [g/cm^3], T [K], P [GPa], e [kJ/g]`, в начале файла комментарии `#` с параметрами области
- ρ ∈ [1e-3, 1e4], T ∈ [0.1, 1e7]; P ∈ [5e-4, 1.6e9] (всегда > 0); e ∈ [-47, 1.7e5] (бывает ≤ 0)

## Этапы

1. **Данные и бейзлайн**: EDA, сечения P и E при 3–4 фиксированных ρ и T, билинейная интерполяция (точность и скорость), сохранение коэффициентов нормирования.
2. **Нейросетевая модель**: Vanilla MLP на PyTorch, производные через autograd в тестовых точках. Результат: кривые обучения, тепловая карта ошибок, карта нарушений устойчивости.
3. **Физические ограничения**: physics-informed loss и обучение PINN; опционально ограничение 0 < c_s < c.
4. **Инференс и упаковка**: размер state_dict, скорость на 10⁵ запросов, экспорт в TorchScript/ONNX, класс-обёртка `predict` / `sound_speed` / `check_physics`, таблица сравнения.
5. **Сжатие и скорость** (доп.): измеримый эффект оптимизации.
6. **Презентация**.

Скорость звука:

c_s² = (∂P/∂ρ)_T + T / (ρ² · (∂E/∂T)_ρ) · (∂P/∂T)_ρ²

## Итоговые метрики

Все модели — на одном test (674 826 узлов таблицы, не участвовавших в обучении), функцией `eos.metrics.evaluate`.
Ошибка P — |ΔP|/P, ошибка e — |Δe|/max(|e|, 1 кДж/г). Полная таблица — `artifacts/metrics_final.csv` (раздел 4.5).

| Модель | Ошибка P, медиана / p99 | Ошибка e, медиана / p99 | ∂P/∂ρ ≤ 0 | ∂e/∂T < 0 | Размер, МБ | Время на 10⁵ запросов, с |
|---|---|---|---|---|---|---|
| Baseline (билинейная интерполяция) | 0.0005% / 0.044% | 0.004% / 0.17% | 0.047% | 0.46% | 34.5 | 0.067 (CPU) |
| Vanilla MLP 256×4 | 2.2% / 22% | 1.9% / 34% | 3.7% | 12.2% | 0.76 | 0.021 (GPU) |
| **PINN 256×4 (GELU, MSE)** | **0.22% / 2.7%** | **0.21% / 4.2%** | **0%** | **0.001%** | 0.76 | 0.013 (GPU T4) |
| PINN, веса float16 | 0.23% / 2.7% | 0.23% / 4.2% | 0% | 0% | 0.38 | — |

Нарушения посчитаны конечными разностями; у Vanilla — во float32, часть из них — шум округления.

## Пример использования API

```python
import sys; sys.path.insert(0, "src")
from eos import EOSModel

model = EOSModel("artifacts/pinn.pt", "artifacts/normalization.json")   # device="cuda" — на GPU
P, e = model.predict(rho, T)          # ГПа, кДж/г; rho в г/см³, T в K (числа или массивы)
cs = model.sound_speed(rho, T)        # км/с
flags = model.check_physics(rho, T)   # mechanical, thermal, sound, consistent, in_domain
```

Без нашего кода: `torch.jit.load("artifacts/pinn_torchscript.pt")(rho, T)` или ONNX Runtime с `artifacts/pinn.onnx`
(входы `rho`, `T` — float32, выходы `P`, `e`).
